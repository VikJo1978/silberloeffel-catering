# Historical implementation packs

These files preserve planning, review boundaries, and implementation reasoning
from earlier project slices. They are intentionally retained for auditability.

They are **not** the current operations manual. For live facts and commands use:

- [Current status](../../current-status.md)
- [Architecture](../../architecture.md)
- [Production runbook](../../runbooks/lenovo-production.md)
- [VPS staging runbook](../../runbooks/vps-staging.md)

Pack statements such as “not yet implemented” describe the moment when that
pack was written and may now be obsolete. Check Git history and current status
before treating a pack as present truth.
